# 算术之间 · Arithmetic Atlas

Jason 的公开算术电路学习导航站。原生 HTML/CSS/JavaScript，无外部运行时依赖。

## 运行与构建

```sh
npm run dev -- --port 4173
npm run build
```

GitHub Pages 从公开仓库根目录发布静态文件；访问地址为 <https://tomasess.github.io/arithmetic-atlas/>。

## 内容

- 六阶段：数制与误差 → 加法与部分积压缩 → Booth 乘法 → 除法 → 浮点运算 → 浮点 PPA。
- 22 个阅读条目（包括配套讲义章节），12 个主线阅读任务。
- 书目与链接于 2026-09-20 核对。每条的 `url` 是原始来源；存在 `evidence` 时，它为辅助核对来源。
- 出版方：Oxford Academic、IEEE、Springer；作者/高校：UCLA、John Hauser、FloPoCo；预印本：arXiv；代码：官方 CVFPU 仓库。
- 不托管第三方教材或论文副本；免费材料和需要购买/机构权限的材料明确区分。
- 学习目标与顺序为本站编排；不作为原作者课程大纲或跨工艺 PPA 结论。

## 交互

搜索支持中英文标题、作者、关键词；可组合主题、类型、免费与状态筛选。阅读状态为未读、在读、已读，记录保存在当前浏览器 localStorage。打开来源标记在读；已读由用户操作确认。JSON 备份可跨浏览器合并，已读优先，忽略未知资源 ID。无分析追踪、无 CDN、无云端进度同步。
